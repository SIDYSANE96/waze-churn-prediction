# Waze User Churn Prediction — Régression logistique binomiale

Projet réalisé dans le cadre du **Google Advanced Data Analytics Professional Certificate** (Coursera).

## Problématique

Identifier les facteurs qui poussent les utilisateurs de l'application Waze à se désabonner (churn), afin d'orienter d'éventuelles actions de rétention.

## Données utilisées

Données comportementales des utilisateurs Waze (dataset fourni dans le cadre de la certification), incluant des variables d'usage de l'application.

## Analyse réalisée

- Nettoyage des données et traitement des valeurs aberrantes
- Feature engineering
- Analyse de la multicolinéarité entre variables
- Entraînement et évaluation d'un modèle de régression logistique binomiale

## Outils

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

## Résultats

Modèle de régression logistique binomiale atteignant **82,6 % d'accuracy** sur la tâche de prédiction du churn.

## Compétences démontrées

Préparation et nettoyage de données, feature engineering, modélisation prédictive, évaluation de modèle (accuracy, analyse de multicolinéarité).
